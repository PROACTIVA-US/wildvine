# `wildvine setup`

Initialize `~/.wildvine/wildvine.json` and the agent workspace.

Related:

- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
wildvine setup
wildvine setup --workspace ~/.wildvine/workspace
```

To run the wizard via setup:

```bash
wildvine setup --wizard
```
